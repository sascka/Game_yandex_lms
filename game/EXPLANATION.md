## 1. Введение

### 1.1. Идея проекта

Проект "Космический Шутер" представляет собой динамичную 2D-игру в жанре космического экшена. Игрок управляет космическим кораблём, защищаясь от бесконечных волн врагов, набирая очки и повышая уровень сложности. Игра создана для демонстрации библиотеки Arcade.

### 1.2. Цели проекта

- Создание полнофункциональной игры с применением всех изученных технологий модуля Arcade
- Разработка чистого, структурированного и расширяемого кода
- Реализация системы уровней, прогрессии сложности и сохранения результатов
- Применение объектно-ориентированного подхода к разработке игр

### 1.3. Задачи проекта

Проект решает следующие задачи:
- Развлекательная: предоставление увлекательного игрового процесса
- Образовательная: демонстрация применения Arcade
- Техническая: создание базы для дальнейшего развития

## 2. Описание реализации

### 2.1. Структура проекта

Проект состоит из одного основного файла `main.py` объёмом более 700 строк кода, который содержит все необходимые классы и функции:

```
space_shooter/
├── main.py              # Основной файл с игровой логикой
├── requirements.txt     # Зависимости проекта
├── README.md           # Документация
├── data/               # Сохранённые данные
│   └── scores.csv      # Таблица рекордов
├── assets/             # Ресурсы (звуки, изображения)
└── levels/             # Конфигурации уровней
```

### 2.2. Архитектура и классы

Проект построен на объектно-ориентированной архитектуре с четким разделением ответственности:

#### 2.2.1. Игровые объекты

**Класс Player**
- Наследуется от `arcade.Sprite`
- Управляет перемещением игрока и стрельбой
- Отслеживает здоровье, счёт и уровень
- Реализует таймер перезарядки оружия

**Класс Enemy**
- Представляет врагов трёх типов: обычные, быстрые и танки
- Каждый тип имеет уникальные характеристики (скорость, здоровье, урон)
- Реализует автоматическую стрельбу с переменным интервалом
- Применяет синусоидальное движение для усложнения

**Класс Boss**
- Финальный босс появляется на 4 уровне
- Имеет 3 фазы, зависящие от здоровья: 1 фаза — веерная атака 2 фаза — круговая атака 3 фаза — хаотический дождь снарядов
- Отображается полоса здоровья босса
- При победе: начисляется +5000 очков, фиксируется победа и игра завершается

**Класс Bullet**
- Универсальный класс для пуль игрока и врагов
- Различает направление движения в зависимости от источника
- Содержит параметр урона
- Визуальный health bar над врагом

**Класс PowerUp**
- Реализует систему бонусов (здоровье, скорость, урон)
- Различные визуальные представления для разных типов

#### 2.2.2. Системы

**Класс ParticleSystem**
- Управляет системой частиц для визуальных эффектов
- Создаёт эффекты взрывов с настраиваемыми параметрами
- Автоматически удаляет "мёртвые" частицы

**Класс Particle**
- Представляет отдельную частицу эффекта
- Реализует физику движения и затухание
- Содержит параметры цвета, размера и времени жизни

**Класс StarField**
- Создаёт анимированный звёздный фон
- Реализует параллакс-эффект с различными скоростями звёзд
- Автоматически перемещает звёзды при выходе за экран

**Класс Camera**
- Реализует эффект тряски экрана при взрывах
- Управляет смещением viewport
- Содержит таймер для постепенного затухания эффекта

#### 2.2.3. Представления (Views)

**MenuView**
- Стартовое окно с инструкциями
- Анимированный фон
- Навигация к игре и таблице рекордов
- Кнопки:
  - ENTER — начать игру
  - H — таблица рекордов

**GameView**
- Основное игровое представление
- Содержит всю игровую логику
- Управляет обновлением и отрисовкой объектов
- Реализует систему столкновений
- Поддержка: паузы (P), победы и поражения

**HighScoreView**
- Отображает топ-10 лучших результатов
- Загружает данные из CSV файла
- Подсвечивает первое место золотым цветом

### 2.4. Игровой процесс

#### 2.4.1. Механика игры

1. **Управление**: 
   - WASD - движение корабля по всему экрану
   - SPACE - стрельба с ограничением скорострельности
   - P - пауза игры

2. **Враги**:
   - Появляются волнами с увеличивающейся частотой
   - Стреляют автоматически
   - Имеют различные характеристики

3. **Прогрессия**:
   - Уровень 1: до 500 очков
   - Уровень 2: 500-1500 очков
   - Уровень 3: 1500-3000 очков
   - Уровень 4: 5000 очков
   - С каждым уровнем враги появляются чаще

4. **Бонусы**:
   - Появляются каждые 10 секунд
   - Восстановление здоровья, увеличение урона и скорости

5. **Условие окончания**:
   - Здоровье игрока достигает 0
   - Победа над боссом
   - Сохранение результата в таблицу рекордов

#### 2.4.2. Баланс сложности

Игра спроектирована с постепенным увеличением сложности:
- Начальная частота спавна врагов: 2 секунды
- Уменьшение интервала на 0.2 секунды за уровень
- Увеличение здоровья врагов на 10 единиц за уровень
- Бонусные очки за врагов растут с уровнем
