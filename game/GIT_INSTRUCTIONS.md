# Инструкции по работе с Git

## Инициализация репозитория

1. Инициализируйте git в папке проекта:
```bash
cd space_shooter
git init
```

2. Добавьте все файлы:
```bash
git add .
```

3. Создайте первый коммит:
```bash
git commit -m "Initial commit: Космический шутер - проект Arcade"
```

## Создание удалённого репозитория

### GitHub

1. Создайте новый репозиторий на GitHub
2. Подключите удалённый репозиторий:
```bash
git remote add origin https://github.com/ваш-username/space-shooter.git
```

3. Отправьте код:
```bash
git branch -M main
git push -u origin main
```

### GitLab

1. Создайте новый проект на GitLab
2. Подключите удалённый репозиторий:
```bash
git remote add origin https://gitlab.com/ваш-username/space-shooter.git
```

3. Отправьте код:
```bash
git push -u origin main
```

### SourceCraft / Яндекс.Контест

1. Получите ссылку на репозиторий от преподавателя
2. Подключите удалённый репозиторий:
```bash
git remote add origin <полученная-ссылка>
```

3. Отправьте код:
```bash
git push -u origin main
```

## Предоставление доступа

### GitHub
1. Settings → Collaborators → Add people
2. Введите username преподавателя

### GitLab
1. Settings → Members → Invite member
2. Выберите роль: Developer или Maintainer

## Регулярные обновления

После внесения изменений:

```bash
# Добавить изменённые файлы
git add .

# Создать коммит с описанием изменений
git commit -m "Описание изменений"

# Отправить на сервер
git push
```

## Примеры коммитов по этапам проекта

```bash
# Этап 1: Описание проекта
git commit -m "Добавлено описание проекта и ТЗ"

# Этап 2: ТЗ + Часть задания выполнена
git commit -m "Реализованы основные классы Player и Enemy"

# Этап 3: Код + Работающая часть
git commit -m "Добавлена система столкновений и стрельба"

# Этап 4: Код + Работающая часть + Черновик документации
git commit -m "Добавлены уровни, частицы и черновик пояснительной записки"

# Этап 5: Код + Пояснительная записка + Презентация + Почти всё работает
git commit -m "Завершена система сохранения и создана презентация"

# Этап 6: Всё готово
git commit -m "Финальная версия проекта готова к защите"
```

## Проверка статуса

```bash
# Посмотреть текущий статус
git status

# Посмотреть историю коммитов
git log --oneline

# Посмотреть изменения
git diff
```

## Полезные команды

```bash
# Отменить последний коммит (если ещё не отправили)
git reset --soft HEAD~1

# Посмотреть удалённые репозитории
git remote -v

# Обновить локальную копию
git pull

# Создать новую ветку для экспериментов
git checkout -b experimental-feature
```

## Структура для сдачи проекта

Убедитесь, что в репозитории есть:

✅ `main.py` - основной код
✅ `requirements.txt` - зависимости
✅ `README.md` - документация
✅ `EXPLANATION.md` - пояснительная записка
✅ `PRESENTATION.md` - шаблон презентации
✅ `data/` - папка с данными
✅ `.gitignore` - список игнорируемых файлов

## Важные замечания

1. **Не коммитьте** файлы из `__pycache__/` - они уже в `.gitignore`
2. **Пишите понятные** сообщения коммитов
3. **Коммитьте часто** - лучше много маленьких коммитов, чем один большой
4. **Не забудьте** дать доступ преподавателю к репозиторию
5. **Сохраняйте** ссылку на репозиторий для отправки в задачу
