# Быстрый старт - Космический Шутер

## Установка

1. Убедитесь, что у вас установлен Python 3.8+:
```bash
python --version
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

Или установите напрямую:
```bash
pip install arcade
```

## Запуск игры

```bash
python main.py
```

## Управление

- **W/A/S/D** - движение корабля
- **SPACE** - стрельба
- **P** - пауза
- **ENTER** - начать игру / вернуться в меню
- **H** - таблица рекордов (в меню)
- **ESC** - вернуться в меню (на экране рекордов)

## Цель игры

- Уничтожайте врагов и набирайте очки
- Избегайте вражеских пуль
- Собирайте бонусы для восстановления здоровья
- Достигайте новых уровней сложности

## Уровни сложности

- **Уровень 1**: 0-500 очков
- **Уровень 2**: 500-1500 очков
- **Уровень 3**: 1500+ очков

## Типы врагов

- 🔴 **Обычные** - стандартные враги
- 🟠 **Быстрые** - быстрые, но слабые
- 🟣 **Танки** - медленные, но прочные

## Очки

- Базовая награда: 50 очков за врага
- Бонус за уровень: +10 очков × текущий уровень

## Проблемы?

Если игра не запускается:
1. Проверьте версию Python (требуется 3.8+)
2. Убедитесь, что arcade установлен корректно
3. Проверьте, что все файлы проекта на месте

## Структура проекта

```
space_shooter/
├── main.py              # Основной файл игры (запускать этот файл)
├── requirements.txt     # Зависимости
├── README.md           # Полная документация
├── EXPLANATION.md      # Пояснительная записка
├── PRESENTATION.md     # Шаблон презентации
├── data/               # Сохранённые данные
│   └── scores.csv      # Таблица рекордов
├── levels/             # Конфигурации уровней
│   └── levels_config.csv
└── assets/             # Место для звуков и изображений (опционально)
```

## Для разработчиков

Код написан в соответствии с PEP 8 и содержит docstring для всех классов.

Основные классы:
- `Player` - игрок
- `Enemy` - враги
- `Bullet` - пули
- `ParticleSystem` - эффекты
- `GameView` - основная игра
- `MenuView` - меню
- `HighScoreView` - рекорды
