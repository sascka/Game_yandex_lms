# Космический Шутер

Проект для курса Arcade в Яндекс.Лицее

## Описание

Космический шутер - динамичная 2D игра, где игрок управляет космическим кораблём и защищается от волн вражеских кораблей. Игра включает систему уровней, бонусы, визуальные эффекты и сохранение рекордов.

## Особенности

### Реализованные технологии

✅ **Стартовое окно** - меню с инструкциями
✅ **Финальное окно** - экран окончания игры с результатами
✅ **Подсчёт результатов** - система очков и уровней
✅ **Спрайты** - все игровые объекты реализованы через спрайты
✅ **Collision Detection** - проверка столкновений между объектами
✅ **Анимация** - анимированный звёздный фон, частицы взрывов
✅ **Несколько уровней** - 3 уровня сложности
✅ **Камера** - эффект тряски при взрывах
✅ **Система частиц** - эффекты взрывов
✅ **Звук** - структура для звуковых эффектов (требуются аудиофайлы)
✅ **Физический движок** - встроенная физика Arcade
✅ **Хранение данных** - сохранение рекордов в CSV

### Игровые механики

- **Три типа врагов**: обычные, быстрые и танки
- **Система здоровья** игрока
- **Бонусы**: восстановление здоровья
- **Прогрессия уровней**: сложность увеличивается с набором очков
- **Таблица рекордов**: топ-10 лучших результатов

## Установка

1. Клонируйте репозиторий:
```bash
git clone <ваш-репозиторий>
cd space_shooter
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите игру:
```bash
python main.py
```

## Управление

- **WASD** - движение корабля
- **SPACE** - стрельба
- **P** - пауза
- **ESC** - возврат в меню (на экране рекордов)
- **ENTER** - начать игру / вернуться в меню

## Классы и модули

### Основные классы

- **Player** - класс игрока с управлением и здоровьем
- **Enemy** - враги с разными характеристиками
- **Bullet** - пули игрока и врагов
- **PowerUp** - система бонусов
- **ParticleSystem** - система частиц для эффектов
- **StarField** - анимированный фон
- **Camera** - камера с эффектом тряски

### Views (окна)

- **MenuView** - стартовое меню
- **GameView** - главное игровое окно
- **HighScoreView** - таблица рекордов
